# Cake Wings by Paba

Website for Cake Wings by Paba: celebration cakes, bento boxes, desserts, surprises and overseas gifting from Uragasmanhandiya, Sri Lanka.

A single-page static site (`index.html`) with hash-based pages. No build step: open `index.html` in a browser or serve the folder with any static server.

- `index.html` is the whole site (HTML, CSS and JavaScript)
- `images/` holds product, gallery, surprise and brand photos
- `cake-wing-new.mp4` is the hero video
